# Brain Challenge Game

Brain Challenge Game is an interactive mini web game built using HTML, CSS, and JavaScript.

## About the Project
This project is based on a memory pattern challenge where the player must observe and repeat the glowing circle sequence correctly. The game also includes bonus challenge rounds to make the gameplay more engaging and interesting.

## Features
- 3x3 interactive circle board
- Memory-based pattern gameplay
- Score tracking
- Round progression
- Lives system
- Bonus quiz and surprise puzzle rounds
- Responsive user interface
- Best score stored using localStorage

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in your browser
